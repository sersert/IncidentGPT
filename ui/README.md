# IncidentGPT UI

React/TypeScript интерфейс: обзор дежурства, очередь инцидентов, алерты,
аналитика, настройки и встроенное руководство `/help`. Рабочие разделы инцидента
сохраняются в `?view=…`; фильтры списка — в query string.

## Запуск

Из каталога `ui`:

```bash
npm install --no-audit --no-fund
npm run dev -- --host 127.0.0.1
```

Откройте `http://127.0.0.1:3000`. Vite проксирует `/api` и `/ws` на backend
`http://localhost:8000`; запустите backend с `LISTEN_ADDR=:8000`. Для новых
авторизованных API backend нужны совпадающие reader credentials. Vite не
подменяет production Basic-auth nginx и не является production сервером.

Для просмотра макета с существующими демонстрационными данными:

```bash
VITE_USE_MOCKS=true npm run dev -- --host 127.0.0.1
```

Жёлтая плашка явно помечает демонстрацию. Часть дополнительных рабочих процессов
обращается к реальному API и в демо может быть недоступна. Макет не проверяет
права, запись изменений, источники или доставку. Не собирайте production образ
с `VITE_USE_MOCKS=true`.

## Темы

Кнопка в шапке переключает `light`/`dark`. До ручного выбора используется
`prefers-color-scheme`; preference хранится в `localStorage` под ключом
`incidentgpt-theme`. Ранний скрипт в `index.html` задаёт `data-theme` до загрузки
bundle, затем ThemeProvider поддерживает системные/storage события. Отключение
storage не ломает интерфейс. Для возврата к системному выбору при разработке
удалите этот ключ и перезагрузите страницу.

Токены обеих палитр живут в `src/index.css`. Для SVG с вычисленными строковыми
цветами используйте `useTheme()`, чтобы подписаться на переключение; CSS custom
properties обновляются напрямую. Не перемонтируйте маршруты ради смены темы:
это теряет несохранённые черновики.

## Проверки

```bash
npx tsc --noEmit -p tsconfig.app.json
npm run build
```

Проверьте десктоп и 390px: меню и его закрытие по Escape, навигацию с клавиатуры,
список с поиском/критичностью/пагинацией и переходы назад/вперёд, вкладки инцидента,
сохранность черновика при переключении вкладки, ошибку сохранения назначения,
пустое состояние и отказ API. Скриншоты и результаты привязывайте к commit PR.
Существующий `npm run lint` требует установки/настройки ESLint, которых в проекте
пока нет; не представляйте его как пройденную проверку.
